# Исправление логики обработки редиректов

## Проблема
Скрипт прерывал сессию при любом редиректе с страницы поиска слотов, включая нормальные системные редиректы на `consularServiceInfo` для обновления данных услуги.

## Старая логика
```
if "dateAndTimeVisitInfo" not in current_url:
    # ВСЕГДА сброс сессии -> перезапуск
    raise SessionResetException("Session was reset")
```

## Новая логика
```
if "dateAndTimeVisitInfo" not in current_url:
    if "consularServiceInfo" in current_url:
        # Нормальный редирект -> вернуться к заполнению данных
        return await perform_consular_steps(page)
    elif "id.e-consul.gov.ua" in current_url:
        # Истекла авторизация -> сброс сессии
        raise SessionResetException("Session expired")
    else:
        # Неожиданный редирект -> подождать и проверить
        # (может быть временная загрузка)
```

## Результат
- ✅ Сохраняется OAuth сессия при редиректах на `consularServiceInfo`
- ✅ Корректно обрабатываются истечения авторизации
- ✅ Система продолжает работу без ненужных перезапусков
- ✅ Редуцированы ложные срабатывания сброса сессии

## Типы редиректов
1. **Нормальные системные**: `consularServiceInfo` - обновление данных услуги
2. **Истечение авторизации**: `id.e-consul.gov.ua` - требуется новый OAuth
3. **Неожиданные**: другие URL - анализ и ожидание

## Логи для отладки
- `📋 Система перенаправила на обновление данных услуги` - нормальный редирект
- `🔐 Обнаружен редирект на авторизацию` - истекла сессия  
- `⚠️ Неожиданный редирект` - требует анализа
